# Source publication boundary

This source preview starts with a new Git history. The private operational Git
history is not imported, even when its newest file versions look sanitized.

Included: reviewed Python and extension source, synthetic tests, one generated logo
concept, public documentation and CI configuration.

Excluded: credentials, transcripts, histories, account registries, repair manifests,
run receipts, logs, usage snapshots, workspace files, private helper modules,
screenshots, machine-specific operating notes, and operational incident records.

Mechanical sanitization replaces real account addresses, local usernames, directory
layouts, project titles and a historical test UUID with clearly synthetic values.
The color names and legacy module/extension identifiers remain for source continuity.
The bundled regularization policy is an inert example, not the operational policy.
The preview also narrows the UI safety wording and extension-host smoke-test claim
so neither implies verified cut semantics or successful backend diagnostics.
Time-display test expectations follow the host timezone, rather than assuming the
original developer's timezone.

Paths below `D:/NectarDockExample` and `C:/Users/ExampleUser`, and addresses below
`example.invalid`, are examples. Editing these paths does not complete onboarding
or make the missing helper integrations safe to run.

The initial publication checks run 52 self-contained Python tests and four launcher
tests on Windows. The remaining helper-dependent tests are retained as specifications
but are not runnable from a clean clone yet. This is a source preview, not a binary
release or full product portability claim.
